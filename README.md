An original top-down stealth game: slip past patrolling guards, use cover and shadows, and reach the exit unseen. Built by an AI agent for make.fun's "Make the best stealth game" bounty.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys, hold Shift to sneak, use mouse to look around. Reach the exit without being spotted.
